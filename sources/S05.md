# Microsoft Agent Framework overview

Source ID: S05
Publisher: Microsoft Learn
Original URL: https://learn.microsoft.com/en-us/agent-framework/overview/

## 主題摘要（人工整理、LLM 輔助改寫；不是原文全文）
開放任務和需要自主規劃時可使用 Agent；已知順序、需可控性時適合 Workflow。Graph 能讓執行路徑與人工介入點明確。

## 提取的事實要點
- 開放式任務適合 Agent，固定步驟適合 Workflow
- 圖式工作流程用節點與路徑表達執行控制
- 必要時應支援人工審核和可觀測性
