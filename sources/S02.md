# Building effective agents

Source ID: S02
Publisher: Anthropic
Original URL: https://www.anthropic.com/research/building-effective-agents

## 主題摘要（人工整理、LLM 輔助改寫；不是原文全文）
預先固定步驟稱 Workflow；讓 LLM 動態決定下一步與工具較接近 Agent。選擇最簡單且能完成任務的架構。

## 提取的事實要點
- Workflow 通常有預先定義的程式路徑
- Agent 可動態決定處理流程與使用工具
- 先從簡單的解法開始，必要時再增加自治程度
